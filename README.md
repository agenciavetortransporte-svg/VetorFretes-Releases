# VetorFretes para Windows

[**Baixar o VetorFretes para Windows x64**](https://github.com/agenciavetortransporte-svg/VetorFretes-Releases/releases/latest/download/VetorFretes-Instalar.exe)

Abra o arquivo **VetorFretes-Instalar.exe**. Na primeira instalação, ele baixa o pacote completo e cria o atalho no menu Iniciar. Nas próximas vezes, use o atalho **VetorFretes**. O programa consulta a versão mais recente antes de abrir e preserva o vínculo existente ao atualizar.

Para vincular seu celular, abra o WhatsApp, toque em **Aparelhos conectados → Conectar um aparelho** e escaneie o código exibido na janela do VetorFretes.

O aplicativo inclui a Evolution API e o PostgreSQL locais. As portas preferenciais são 47831 e 47832. O aplicativo escolhe outras portas quando necessário.

[Ver versões publicadas](https://github.com/agenciavetortransporte-svg/VetorFretes-Releases/releases)
